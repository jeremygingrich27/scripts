================================================================================
                        VASP QUICK REFERENCE
================================================================================
Vienna Ab initio Simulation Package (VASP) — input/output files and key tags
Functional: PBEsol+U unless noted. Assumes spin-polarized magnetic calculations.
================================================================================


================================================================================
  INPUT FILES
================================================================================

INCAR
  The main control file. A plain-text list of keyword = value pairs.
  Controls every aspect of the calculation: what to compute, how many steps,
  convergence thresholds, magnetism, parallelisation, etc.
  Only tags that differ from VASP defaults need to be specified.
  See the INCAR TAGS section below for details.

POSCAR
  Crystal structure file. Specifies the lattice vectors and atomic positions.

  Format (VASP 5+):
    Line 1  : comment (arbitrary)
    Line 2  : universal scaling factor (Å); negative means volume in Å³
    Lines 3-5: lattice vectors a1, a2, a3 (rows, in Å if scale=1)
    Line 6  : element symbols (e.g. "Cu O")
    Line 7  : number of atoms per species (e.g. "32 32")
    Line 8  : "Direct" (fractional) or "Cartesian"
    Lines 9+: atomic positions

  The order of atoms must match the order in POTCAR exactly.
  After a relaxation, CONTCAR (the updated structure) should be used as POSCAR
  for the next calculation.

KPOINTS
  Defines the k-point sampling of the Brillouin zone. Three common formats:

  Automatic (Monkhorst-Pack):
    Automatic Mesh
    0
    Gamma          ! or Monkhorst
    4 4 4          ! subdivisions along each reciprocal lattice vector
    0 0 0          ! optional shift

  Line-mode (band structure):
    K-Path
    20             ! points per segment
    Line-Mode
    Reciprocal
    0.0 0.0 0.0  ! Gamma
    0.5 0.0 0.0  ! X
    (blank line between segments)

  Explicit list:
    Explicit
    N              ! number of k-points
    Reciprocal
    k1x k1y k1z  weight
    ...

  VASP reads only a file named exactly "KPOINTS". If this file is missing,
  VASP uses an automatic 2×2×2 mesh, which is rarely what you want.

POTCAR
  Concatenated PAW pseudopotential file. One block per species, in the same
  order as POSCAR. Generated by concatenating the individual POTCAR files:
    cat Cu/POTCAR O/POTCAR > POTCAR
  Use PBEsol potentials (directory named potpaw_PBE.54 or similar on TACC).
  Recommended potentials for common elements:
    Cu  → Cu_pv   (semi-core 3p included)
    O   → O
    Ti  → Ti_sv
    Fe  → Fe_pv
    Ca  → Ca_sv


================================================================================
  OUTPUT FILES
================================================================================

OUTCAR
  The most complete output file. Contains everything: energy, forces, stress,
  magnetic moments, timing, charge analysis, and convergence info for every
  ionic and electronic step. Always check this file when something goes wrong.

  Useful greps:
    grep "TOTEN"         OUTCAR   # total energy at each step
    grep "free energy"   OUTCAR   # free energy (includes -TS term)
    grep "magnetization" OUTCAR   # total and site-resolved magnetic moments
    grep "General timing" OUTCAR  # present only if job completed cleanly
    grep "reached required" OUTCAR # ionic convergence message

OSZICAR
  Compact convergence log. One line per electronic step, one block per ionic
  step. Useful for quickly checking whether the SCF converged each step.

  Format per electronic step:
    N   E              dE        d eps      ncg    rms          rms(c)
    1  -100.00000000  -1.0E+02  -1.0E+02   200  0.123E+00  0.456E-01

  The final "F=" line gives the free energy after each ionic step.

CONTCAR
  Updated POSCAR written after each ionic step (and at the end of the run).
  Contains the final structure (and velocities if NSW > 0 with IBRION=0).
  Always use CONTCAR as POSCAR for the next calculation in a relaxation chain.

EIGENVAL
  Eigenvalues (band energies) at each k-point and band index, for both spin
  channels. Used by sumo-bandplot and similar tools.
  Format: header, then blocks of  k-point weight + band energies.

DOSCAR
  Density of states. First block is the total DOS; subsequent blocks are
  site-projected DOS for each atom. Requires LORBIT ≥ 10 for orbital resolution.
  sumo-dosplot and vaspkit can parse this.

PROCAR
  Orbital- and site-projected band character at every k-point.
  Required for fat-band / orbital-projected band structure plots.
  Written when LORBIT = 11 (or 12 for phase information).

CHGCAR
  Charge (and spin) density on the real-space grid, written in VASP format.
  Required for:
    - NSCF runs  (ICHARG = 11 reads CHGCAR, fixes charge density)
    - Band unfolding NSCF runs
    - Restarting from a known magnetic state
  Large file (~several GB for large supercells). Contains both up+down and
  up-down charge densities for spin-polarized calculations.

CHG
  Lighter version of CHGCAR: charge density only, no augmentation charges.
  Useful for charge density visualization (VESTA). NOT suitable for restarting
  calculations (use CHGCAR for that).

WAVECAR
  Binary file containing the plane-wave coefficients of all Kohn-Sham orbitals.
  Required by:
    - easyunfold (band unfolding spectral weights)
    - NSCF restarts when ISTART = 1 (initial wavefunction guess)
  Very large (~10–100 GB for big supercells). Often the biggest file in a run.

vasprun.xml
  XML-format output containing essentially everything in OUTCAR, plus the PDOS,
  eigenvalues, and structure at each step in a machine-readable format.
  The primary input for pymatgen, sumo, VESTA, and most post-processing tools.

IBZKPT
  List of irreducible k-points used in the calculation (after symmetry
  reduction), with their weights. Useful for verifying the k-mesh.

XDATCAR
  Ionic trajectory: one POSCAR-format snapshot per ionic step.
  Used for visualising relaxation paths or MD trajectories (OVITO, VESTA).

REPORT
  Written by phonopy/DFPT workflows. Contains force constant information.
  In standard VASP runs, OUTCAR serves this purpose.

DYNMAT
  Dynamical matrix from a finite-displacement or DFPT phonon run
  (IBRION = 5, 6, 7, or 8).


================================================================================
  INCAR TAGS
================================================================================

Organised by category. Default values shown in parentheses where notable.

────────────────────────────────────────────────────────────────────────────────
  ELECTRONIC CONVERGENCE
────────────────────────────────────────────────────────────────────────────────

ENCUT       Plane-wave kinetic energy cutoff (eV).
            Should be at least the maximum ENMAX in POTCAR, ideally 1.3×.
            Use the same ENCUT for all calculations being compared.
            Typical values: 400–600 eV.

EDIFF       Energy convergence criterion for the SCF loop (eV). (1E-4)
            The SCF is considered converged when the change in total energy
            between steps is less than EDIFF.
            Use 1E-6 for relaxations, 1E-7 for accurate electronic properties.

NELM        Maximum number of electronic (SCF) steps per ionic step. (60)
            If the SCF does not converge within NELM steps, VASP moves on.
            Increase to 100–200 for difficult magnetic systems.

NELMIN      Minimum number of SCF steps before convergence is checked. (2)
            Increase to 6–8 to prevent premature convergence from a lucky
            first step.

PREC        Precision mode controlling FFT grid size and energy cutoff.
            Normal   : standard, good for most relaxations
            Accurate : larger FFT grid, required for NSCF and band calculations
                       to avoid wrap-around errors

IALGO / ALGO
            Electronic minimisation algorithm.
            ALGO = Normal   (IALGO = 38): Davidson block iteration. Robust,
                             good for metals and insulators.
            ALGO = Fast     (IALGO = 68): RMM-DIIS. Faster but less stable;
                             good for large systems once close to convergence.
            ALGO = All      (IALGO = 58): alternating DIAG+RMM-DIIS.
            ALGO = VeryFast (IALGO = 48): purely RMM-DIIS, fastest but least
                             stable. Not recommended for magnetic systems.
            Use IALGO = 38 / ALGO = Normal for magnetic LDA+U calculations.

LREAL       Real-space projection of operators.
            .FALSE. : reciprocal space (exact, required for small cells)
            Auto    : VASP decides; suitable for large supercells (≥ ~50 atoms)
            Use .FALSE. for cells with fewer than ~50 atoms for accuracy.

ADDGRID     Add an additional support grid for augmentation charges. (.FALSE.)
            Set .TRUE. to improve convergence with GGA functionals, especially
            for forces and stress. Small computational cost.

────────────────────────────────────────────────────────────────────────────────
  STARTING POINT — CHARGE AND WAVEFUNCTIONS
────────────────────────────────────────────────────────────────────────────────

ISTART      How to initialise the wavefunctions.
            0 : start from scratch (WAVECAR ignored)
            1 : read WAVECAR (restart from previous run; k-grid must match)
            2 : restart with constant charge density from WAVECAR
            If WAVECAR is absent or k-grids mismatch, VASP falls back to 0.

ICHARG      How to initialise the charge density.
            0 : construct from WAVECAR (uses ISTART result)
            1 : read CHGCAR and keep updating (standard SCF restart)
            2 : superposition of atomic charge densities (fresh start)
            11: read CHGCAR and fix it (NSCF, non-self-consistent field).
                Used for band structure, NSCF DOS, and band unfolding runs.
                Requires ISTART = 1 or ISTART = 0.

LWAVE       Write WAVECAR at the end of the run. (.TRUE.)
            Set .TRUE. whenever downstream calculations need the wavefunctions
            (band unfolding, NSCF restart).
            Set .FALSE. to save disk space when WAVECAR is not needed.

LCHARG      Write CHGCAR and CHG at the end of the run. (.TRUE.)
            Set .TRUE. for SCF runs that feed into NSCF runs.
            Set .FALSE. in NSCF runs to avoid overwriting the SCF CHGCAR.

────────────────────────────────────────────────────────────────────────────────
  IONIC RELAXATION
────────────────────────────────────────────────────────────────────────────────

NSW         Number of ionic steps. (0)
            0 for single-point / NSCF calculations.
            Set to a large number (e.g. 200) for relaxations.

IBRION      Ionic update algorithm.
            -1 : no ionic update (NSW must be 0)
             1 : quasi-Newton (RMM-DIIS); good for hard relaxations
             2 : conjugate gradient; robust, good default for relaxations
             5 : finite displacements for force constants (phonons)

ISIF        What to relax.
            2 : ions only (lattice fixed)
            3 : ions + cell shape + cell volume (full relaxation)
            4 : ions + cell shape (volume fixed)
            7 : cell volume only (ions fixed, useful for EOS)
            Use ISIF=3 for full structural relaxation.

EDIFFG      Convergence criterion for ionic relaxation.
            Positive: energy change between steps (eV)
            Negative: maximum force on any atom (eV/Å); e.g. -0.01
            Use negative (force-based) convergence for reliable structures.
            Typical: EDIFFG = -0.01 for relaxations, -0.001 for phonons.

POTIM       Step size for ionic updates (Å for IBRION=1,2; fs for MD). (0.5)
            Reduce to 0.1–0.2 if relaxation diverges.

────────────────────────────────────────────────────────────────────────────────
  SMEARING
────────────────────────────────────────────────────────────────────────────────

ISMEAR      Occupation function for partial occupancies.
            -5 : tetrahedron method with Blöchl corrections. Most accurate for
                 insulators and semiconductors with a dense k-mesh. Cannot be
                 used with < 4 k-points or for metallic systems.
            0  : Gaussian smearing. Safe for insulators and small-gap systems.
            1  : Methfessel-Paxton order 1. Recommended for metals.
            Use ISMEAR = 0 with SIGMA = 0.05 as a safe default for insulators.
            Use ISMEAR = -5 for final DOS calculations of insulators.

SIGMA       Smearing width (eV). (0.2)
            Reduce until total energy is converged with respect to SIGMA.
            Typical: 0.05 for insulators, 0.1–0.2 for metals.
            For ISMEAR = -5, SIGMA has no effect.

────────────────────────────────────────────────────────────────────────────────
  MAGNETISM
────────────────────────────────────────────────────────────────────────────────

ISPIN       Spin polarisation.
            1 : non-spin-polarised
            2 : spin-polarised (collinear)

MAGMOM      Initial magnetic moments on each atom (in μB).
            One value per atom, in the same order as POSCAR.
            For collinear: MAGMOM = +3.0 -3.0 0 0 ...
            Ferromagnetic start: all same sign.
            Antiferromagnetic start: alternating signs.
            The SCF will converge to whatever magnetic state is energetically
            favoured; MAGMOM only sets the starting point.

NUPDOWN     Fix the difference between spin-up and spin-down electrons.
            Useful for constraining total moment when VASP drifts.

────────────────────────────────────────────────────────────────────────────────
  LDA+U (Hubbard correction)
────────────────────────────────────────────────────────────────────────────────

LDAU        Activate LDA+U. (.FALSE.)
            Set .TRUE. for transition metals with localised d or f electrons.

LDAUTYPE    Flavour of LDA+U.
            1 : Liechtenstein — separate U and J parameters
            2 : Dudarev — single effective U_eff = U - J parameter (most common)

LDAUL       Angular momentum channel for each species (-1 = none, 2 = d, 3 = f).
            Example for Cu O: LDAUL = 2 -1

LDAUU       U parameter (eV) for each species.
            Example: LDAUU = 7.00 0
            For Cu: U_eff = 7 eV (Ref: J. Phys. Chem. C 119, 28, 2015).

LDAUJ       J parameter (eV) for each species (0 when using LDAUTYPE = 2).

LMAXMIX     Maximum l quantum number for charge density mixing. (2)
            CRITICAL for LDA+U with d-electrons: set LMAXMIX = 4.
            Without this, VASP truncates charge density mixing at l=2,
            ignoring d-channel components and causing slow or inaccurate
            convergence of magnetic moments and the band gap.
            Set LMAXMIX = 6 if f-electrons (lanthanides/actinides) are involved.

LDAUPRINT   Verbosity of LDA+U output in OUTCAR.
            0 : silent, 1 : occupancy matrix, 2 : occupancy + potential matrix

────────────────────────────────────────────────────────────────────────────────
  CHARGE DENSITY MIXING
────────────────────────────────────────────────────────────────────────────────

  Relevant for difficult magnetic systems where default mixing causes
  oscillations or convergence to the wrong state.

AMIX        Linear mixing parameter for charge density. (0.4)
            Reduce to 0.1–0.2 for strongly correlated / magnetic systems.

BMIX        Kerker mixing cutoff wavevector (1/Å). (1.0)
            Setting BMIX = 0.0001 effectively disables Kerker preconditioner,
            which can help for insulators where long-wavelength components
            dominate.

AMIX_MAG    Linear mixing parameter for spin density. (1.6)
            Reduce to 0.4–0.8 for antiferromagnetic systems.

BMIX_MAG    Kerker cutoff for spin density. (1.0)
            Setting to 0.001 disables preconditioner for spin density.

IMIX        Mixing algorithm. (4 = Broyden)
            4 is the default and works well in most cases.

────────────────────────────────────────────────────────────────────────────────
  OUTPUT AND POST-PROCESSING
────────────────────────────────────────────────────────────────────────────────

LORBIT      Controls what is written to PROCAR and DOSCAR.
            0  : no projections
            10 : lm-decomposed DOSCAR, no PROCAR
            11 : lm-decomposed DOSCAR + PROCAR (most common choice)
            12 : as 11 plus phase information in PROCAR
            Use LORBIT = 11 for any calculation where you want orbital- or
            site-projected DOS or fat bands.

NEDOS       Number of points in the energy grid for the DOS. (301)
            Increase to 2000–3000 for smooth DOS plots.

EMIN/EMAX   Energy range for the DOS (eV, relative to vacuum, not Fermi level).
            Defaults to span all occupied + some unoccupied states.

NWRITE      Frequency of OUTCAR output. (2)
            0 : minimal, 1 : normal, 2 : full (default), 3 : debug

LASPH       Non-spherical contributions to gradient corrections. (.FALSE.)
            Set .TRUE. for accurate forces and energies with GGA, especially
            for systems with aspherical charge densities (transition metals).

────────────────────────────────────────────────────────────────────────────────
  FUNCTIONAL
────────────────────────────────────────────────────────────────────────────────

GGA         GGA functional to use.
            PE : PBE (default for VASP with PBE POTCARs)
            PS : PBEsol — recommended for solids; better lattice constants
            AM : AM05
            RP : revPBE

GGA_COMPAT  Apply GGA compatibility corrections for gradient. (.TRUE.)
            Set .FALSE. with GGA = PS (PBEsol) to use the correct functional
            without PBE-compatibility adjustments.

VOSKOWN     Use Vosko-Wilk-Nusair interpolation for correlation. (0)
            Set VOSKOWN = 1 with PBEsol (GGA = PS) for consistency.

────────────────────────────────────────────────────────────────────────────────
  BANDS AND K-POINTS
────────────────────────────────────────────────────────────────────────────────

NBANDS      Number of bands to compute.
            Default is NELECT/2 + NIONS/2 (with some buffer).
            Increase for unoccupied states (optical spectra, band structure).

NKDIV       Not a standard tag; k-mesh is set in KPOINTS.

────────────────────────────────────────────────────────────────────────────────
  PARALLELISATION
────────────────────────────────────────────────────────────────────────────────

NCORE       Number of CPU cores that work on a single orbital.
            Total MPI ranks = NCORE × NPAR × KPAR.
            Typical: NCORE = number of cores per node (e.g. 16 or 32 on LS6).

KPAR        Number of k-point groups computed in parallel.
            Useful when you have many k-points and many nodes.
            Must divide evenly into the total number of irreducible k-points.
            Default 1 (no k-point parallelisation).

NSIM        Number of bands optimised simultaneously in RMM-DIIS. (4)
            Increase to 8–16 for better parallel efficiency with many bands.

────────────────────────────────────────────────────────────────────────────────
  VAN DER WAALS
────────────────────────────────────────────────────────────────────────────────

IVDW        Activate vdW dispersion correction.
            0  : none (default)
            11 : DFT-D3 (Grimme, zero damping)
            12 : DFT-D3 with Becke-Johnson damping (recommended with DFT-D3)
            20 : Tkatchenko-Scheffler

────────────────────────────────────────────────────────────────────────────────
  HYBRID FUNCTIONALS (HSE06)
────────────────────────────────────────────────────────────────────────────────

LHFCALC     Activate Hartree-Fock / hybrid functional. (.FALSE.)

AEXX        Fraction of exact exchange. (0.25 for PBE0, 0.25 for HSE06)

HFSCREEN    Range-separation parameter (1/Å). (0 for PBE0, 0.2 for HSE06)
            HSE06: LHFCALC = .TRUE.  AEXX = 0.25  HFSCREEN = 0.2

ALGO        Must be set to All (IALGO = 58) or Damped for hybrid calculations.


================================================================================
  COMMON CALCULATION RECIPES
================================================================================

SCF single-point (insulator/magnetic)
  ISTART=0 or 1, ICHARG=2 or 1, NSW=0, ISMEAR=0, SIGMA=0.05
  LWAVE=.TRUE., LCHARG=.TRUE., LMAXMIX=4 (if d/f), LORBIT=11

Ionic relaxation (full)
  NSW=200, IBRION=2, ISIF=3, EDIFFG=-0.01
  LWAVE=.FALSE., LCHARG=.FALSE. (unless you need them)

NSCF band structure
  ICHARG=11, ISTART=1, NSW=0, ISMEAR=0
  KPOINTS in line-mode, LORBIT=11
  LCHARG=.FALSE. (don't overwrite SCF CHGCAR)

NSCF DOS (uniform mesh)
  ICHARG=11, ISTART=1, NSW=0, ISMEAR=-5 (or 0 if <4 kpts)
  Dense Gamma-centred KPOINTS, NEDOS=2000, LORBIT=11
  LCHARG=.FALSE.

Band unfolding NSCF (easyunfold)
  ICHARG=11, ISTART=0 or 1, NSW=0, ISMEAR=0, LMAXMIX=4
  KPOINTS from KPOINTS_easyunfold (must be named exactly KPOINTS)
  LWAVE=.TRUE. (easyunfold reads this WAVECAR), LCHARG=.FALSE.


================================================================================
  QUICK DIAGNOSTIC COMMANDS
================================================================================

Did the job finish?
  grep "General timing and accounting" OUTCAR

Did the SCF converge each step?
  grep "RMM\|DAV\|reached" OUTCAR | tail -30

What are the final magnetic moments?
  grep "magnetization" OUTCAR | tail -5

What is the final total energy?
  grep "TOTEN" OUTCAR | tail -1

What forces remain?
  grep "TOTAL-FORCE" -A $((NATOMS+1)) OUTCAR | tail -$((NATOMS+2))

How many k-points are actually used?
  grep "NKPTS" OUTCAR | head -1

What ENCUT and ENMAX are being used?
  grep "ENCUT\|ENMAX" OUTCAR | head -5

================================================================================
